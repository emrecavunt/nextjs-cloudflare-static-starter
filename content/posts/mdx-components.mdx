<TLDR>
  Every block on this page is a React component in `components/mdx/`, wired once
  in `mdx-components.tsx`. Use them from any `.mdx` file with plain JSX — no
  imports, no registry edits.
</TLDR>

## Code blocks

Fenced code is highlighted by Shiki **at build time**, so the reader downloads
zero highlighting JavaScript — the only client JS a block ships is its copy
button:

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`
}
```

The language tag and the line numbers are pure CSS in `app/globals.css`,
which is why copying a block never pastes the chrome. Restyling means
editing a stylesheet, not a highlighter config.

## Images

has no optimizer to infer sizes for you, so you say what you mean:

## Make them yours

Open `components/mdx/` and delete what you don't need: every component is
self-contained, `mdx-components.tsx` is the only registry, and the e2e suite
(`tests/e2e/mdx-components.spec.ts`) pins the contract so a pipeline upgrade
can't silently un-style your posts.
